# ⚛️ Krypton

Krypton is a modern chemistry learning platform built for elementary and secondary school students.  
The platform focuses on structured learning, conceptual understanding, and clean educational design instead of mechanical memorization.

---

# 🌍 About The Project

Krypton was created to make chemistry easier, more understandable, and more engaging for students.

The platform presents learning material in a logical and organized way, helping students:

- understand chemistry concepts step-by-step
- improve analytical thinking
- learn through structured explanations
- explore chemistry using interactive resources

Instead of overwhelming students with memorization, Krypton focuses on clarity and understanding.

---

# ✨ Features

- 🌐 English & Georgian language support
- ⚛️ Structured chemistry lessons
- 📚 Organized educational resources
- 🧪 Interactive and clean UI
- 🔍 Search & database system
- 📱 Responsive modern design
- 🌙 Dark themed interface
- 🚀 Fast and optimized frontend

---

# 🛠️ Tech Stack

- ⚡ Next.js
- ⚛️ React
- 🎨 Tailwind CSS
- 🟨 TypeScript
- 🍃 MongoDB

---

# 🌍 Localization

Krypton currently supports:

- English
- Georgian

Important pages and educational content are translated manually to ensure high-quality chemistry terminology and accurate explanations.

---

# 🎯 Project Goal

The goal of Krypton is to transform chemistry from a difficult and overwhelming subject into an understandable and intellectually engaging learning experience.

The platform aims to:

- support students
- improve educational accessibility
- simplify difficult chemistry concepts
- encourage curiosity and critical thinking
