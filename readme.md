Krypton: Chemistry Database Project
A high-performance web application built to manage and filter chemistry-related resources, tasks, and projects. This project leverages a modern tech stack to ensure a fast, responsive, and type-safe user experience.

🚀 Tech Stack
Framework: Next.js

Language: TypeScript to ensure robust type safety across the application.

Database: MongoDB for flexible, NoSQL data storage.

Styling: Tailwind CSS for a clean, "hacker-dark" aesthetic with high-contrast accents.

🛠️ Features
Dynamic Routing: Uses Next.js dynamic segments to handle resource, task, and project categories within a single layout.

Real-time Filtering: A custom Filter component that allows users to sort through chemical data efficiently.

Database Integration: Server-side fetching directly from MongoDB using a singleton client pattern for performance.

Responsive Design: Fully optimized for mobile and desktop, featuring a high-contrast dark mode UI.
